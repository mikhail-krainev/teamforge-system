## Оценка пробела `AuthzRegistry` (пункт 4 задания)

Уровень: **HIGH** (S1R-03), а не MEDIUM, как записано в `docs/backlog.md:49`.

Основание:

- Это явный критерий приёмки S1-13 и единственная проверка в разделе "IDOR" среза 1 ("приложение не стартует при операции без `x-authz`").
- Реестр - точка применения SEC-03 на рантайме. Остальное (`check-contract.mjs`, `idorMatrix`) работает на CI и в тестах и не помешает запустить контроллер без guard.
- Исправление небольшое (реестр, глобальный guard "запретить по умолчанию", один модульный тест) и дешевле, чем исправлять открытые маршруты в срезах 2-7.

Не блокирует: в срезе 1 у приложения нет защищённых ресурсов, поэтому прямого ущерба сегодня нет. Блокирует начало среза 2.

## Что сделано хорошо

- Транзакции: `SET LOCAL` только внутри транзакции, `prepare: false`, нет сессионных блокировок и `LISTEN/NOTIFY`, интервал в `SET LOCAL` проверяется регулярным выражением. Повтор при `40P01`/`40001` с джиттером и тест настоящего взаимоблокирования (`attempts > 2`), порядок блокировок проверяется в тестовом режиме.
- Идемпотентность: захват вне транзакции, `lock_token` как fencing, запись результата последним оператором, тест "медленный запрос теряет захват и откатывается" (мутант без проверки токена убит). Распознавание ошибок БД по имени ограничения.
- Лимитер: один Lua-скрипт с временем Redis, ключи через HMAC (нет IP и email в открытом виде); тест 30 параллельных вызовов при пороге 5 действительно ловит неатомарную реализацию.
- Журналы: собственные сериализаторы без `url/query/headers`, тест на отсутствие токена в строке запроса (кроме S1R-01).
- Инфраструктура: образы по digest, `USER node`, `.dockerignore` исключает `.env*`, `migrate` на прямом соединении с `service_completed_successfully`, пароли Redis подставляются в ACL при старте (не в образе), проверка `ACL WHOAMI` при старте.
- CI: `permissions: contents: read`, SHA-пины проверены, `pull_request` без секретов, `gitleaks` по истории, `pnpm audit signatures`.
- Тесты: `barrier(N)`, подсчёт `pg_stat_database.deadlocks` после каждого прогона, явный пропуск интеграционных тестов с видимой причиной, `--repeat 5` для `test/concurrency`.
