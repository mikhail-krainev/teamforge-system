## 1. `minimumReleaseAgeExclude`: свежие версии, закреплённые точно (S1R-11)

**Политика.** Установка пакетов (`pnpm install`) отвергает версии младше `minimumReleaseAge` (в `pnpm-workspace.yaml` задано явно: 1440 минут = 1 сутки). Architecture 13.18 требует 14 суток для обновлений (Renovate `minimumReleaseAge: 14 days`, `.github/dependabot.yml` - `cooldown`). Срок в 14 суток нельзя включить для установки целиком: проверено, что при 20160 минутах lockfile отвергают ещё 90 пакетов (`pnpm install --frozen-lockfile` падает), потому что весь стек выбран в первые дни после выхода релизных линий.

**Исключения.** 38 точных версий ниже опубликованы 2026-10-11 .. 2026-10-12 (на дату создания среза 1, 2026-10-13, им менее 2 суток). Версии закреплены точно (без `^`/`~`), записаны в `pnpm-lock.yaml` с контрольными суммами. Исключение нужно только для того, чтобы `pnpm install --frozen-lockfile` проходил; шаблона и диапазонов в списке нет.

**Чем компенсировано.**

- Версии закреплены точно, `pnpm-lock.yaml` единственный и проверяется в CI (`deps:check`); `pnpm install --frozen-lockfile`.
- CI: `pnpm audit --prod --audit-level=high` блокирует слияние, `pnpm audit signatures` проверяет подписи реестра.
- Скрипты установки выключены (`allowBuilds` в `pnpm-workspace.yaml`).
- Часть записей (`@typescript-eslint/*`, `vitest`, `@vitest/*`, `dependency-cruiser`) - инструменты разработки: их нет в боевых образах (`pnpm deploy --prod`).
- Для ядра сервера (`@nestjs/*`, `bullmq`, `@aws-sdk/*`, `zod`) риск принят осознанно: переход на более старые линии означал бы отказ от NestJS 12 / BullMQ 6, выбранных ADR; вместо этого срок пересмотра короткий.

**Пересмотр: 2026-10-27** (14 суток после самой поздней публикации в списке), либо при первом обновлении зависимостей в срезе 2, что наступит раньше. На пересмотре: (а) обновить закрепления до версий старше 14 суток или подтвердить текущие; (б) убрать из `minimumReleaseAgeExclude` каждую запись, которой исполнилось 14 суток, и поднять `minimumReleaseAge` до 20160; (в) проверить `pnpm audit` и advisory по каждому семейству.
