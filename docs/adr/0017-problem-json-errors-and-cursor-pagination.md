# ADR-0017. Ошибки в формате RFC 9457 (problem+json) и курсорная пагинация

Статус: принято. Дата: 2026-10-12. Фаза 3. Обновлено в фазе 3 по ревью архитектуры.

## Контекст

Клиенту нужно надёжно различать отказы конкурентного доступа (`SEAT_TAKEN`, `TEAM_FULL`, `PROJECT_LIMIT`, `VERSION_CONFLICT` с актуальным состоянием, `STAGE_TRANSITION_BLOCKED` со списком невыполненного). Тексты ошибок локализуются (i18n), поэтому на них нельзя опираться. Spec 5.2: пагинация по курсору, 20 по умолчанию, максимум 100.

## Решение

- Все ошибки - `application/problem+json` по RFC 9457: `type`, `title`, `status`, `detail`, `instance`, плюс расширения `code` (стабильный машинный код из перечисления `ErrorCode`), `requestId`, `errors[]` (поля, JSON Pointer), `unmet[]` (невыполненные условия), `current` (ресурс при `VERSION_CONFLICT`), `retryAfterSeconds`.
- Перечисление `ErrorCode` только расширяется; смысл существующего кода не меняется (закон Хайрама: клиенты будут на них опираться).
- Отображение ошибок PostgreSQL на коды - по имени ограничения; неизвестное нарушение уникальности - 500 (ошибка программиста).
- Пагинация - keyset: непрозрачный курсор (base64url JSON с ключом сортировки и хэшем фильтров), `limit` 1..100, ответ `{ items, nextCursor }`; общего числа элементов нет.
- `Problem.unmet[].code` - перечисление `UnmetCode` (только расширяется). Курсор есть у всех списков, включая `listStackTags` и `listAvailableRepositories` (у последнего курсор - подписанная обёртка номера страницы GitHub); без курсора только `listRoles` с жёстким пределом 200 строк.

## Последствия

- Плюсы: единый формат ошибок во всех модулях; клиент ветвится по `code`; страницы стабильны при вставках и не деградируют на больших смещениях.
- Минусы: нельзя перейти на произвольную страницу (для MVP не требуется); курсор привязан к набору фильтров.

## Альтернативы

- Собственный формат `{ error: { code, message } }`: не стандарт, нет готовой поддержки в клиентах. Отклонено.
- Пагинация `page/pageSize` с `totalItems`: дорогой `count(*)`, дубли и пропуски при вставках. Отклонено.
